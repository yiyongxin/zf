# 记忆系统

这是子房智能体的文件化记忆系统。整个 `memory/` 目录可以独立迁移到其他智能体项目中。

## 目录结构

```
memory/
├── README.md            # 本文件 — 记忆系统说明
├── identity.md          # 智能体身份定义（迁移后修改此文件即可换身份）
├── user-profile.md      # 用户画像与偏好
├── knowledge/           # 长期知识库（按主题分文件）
├── conversations/       # 对话摘要（按日期命名）
└── tasks/               # 任务追踪（按任务命名）
```

## 迁移指南

1. 将整个 `memory/` 目录复制到新项目
2. 修改 `identity.md` 中的智能体名称和身份
3. 在新项目的 `.github/copilot-instructions.md` 中引用此记忆系统
4. 完成 — 用户画像、知识库、任务等全部保留

## 文件命名规范

- `knowledge/` 下按主题命名：`python.md`、`docker.md`、`项目架构.md`
- `conversations/` 下按日期命名：`2026-04-15.md`
- `tasks/` 下按任务命名：`搭建博客.md`、`学习rust.md`

## 记忆格式规范

所有记忆文件使用 Markdown 格式，遵循以下原则：

1. **一级标题**：文件主题
2. **二级标题**：分类
3. **列表项**：具体条目，格式为 `- [日期] 内容`
4. **保持简洁**：每条记忆一行，不写长段落

这样低等级模型也能轻松解析和更新。
